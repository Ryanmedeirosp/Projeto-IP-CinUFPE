# assets/sounds/

Efeitos sonoros curtos.

## O que colocar aqui
- Som de coleta (pode ser um diferente para cada tipo de coletável): `collect_coin.wav`, `collect_gem.wav`...
- Som de colisão/dano: `hit.wav`.
- Som de vitória e de game over: `win.wav`, `game_over.wav`.
- Som de clique em botões do menu: `click.wav`.

## Recomendações
- Preferir `.wav` ou `.ogg` (o pygame carrega bem os dois).
- Sons curtos e com volume parecido entre si.

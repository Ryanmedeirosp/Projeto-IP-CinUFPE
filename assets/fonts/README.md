# assets/fonts/

Fontes usadas nos textos do jogo (HUD, menus, tela de game over).

## O que colocar aqui
- Arquivos `.ttf` ou `.otf` (ex.: `pixel_font.ttf`).

## Por que guardar a fonte no projeto
Se o jogo usar uma fonte do sistema (`pygame.font.SysFont`), ela pode não existir no computador da apresentação. Com o arquivo aqui, o texto aparece igual em qualquer máquina.

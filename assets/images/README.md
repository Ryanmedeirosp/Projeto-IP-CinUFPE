# assets/images/

Imagens usadas no jogo.

## O que colocar aqui
- **Jogador**: sprite do objeto controlado pelo usuário (ex.: `player.png`).
- **Coletáveis**: uma imagem para cada um dos **3 tipos obrigatórios** (ex.: `coin.png`, `gem.png`, `star.png`).
- **Inimigos/obstáculos** (opcional): `enemy.png`.
- **Cenário**: `background.png`.
- **Interface**: ícones do HUD (um ícone por tipo de coletável ao lado do contador), botões e telas de menu/game over.

## Recomendações
- Formato `.png` (aceita transparência).
- Manter os tamanhos coerentes com as dimensões definidas em `constants.py`.
- Se o jogo tiver animações, criem subpastas por personagem (ex.: `images/player/walk_1.png`).

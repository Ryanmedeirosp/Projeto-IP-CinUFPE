# docs/screenshots/

Capturas de tela do jogo **funcionando**. São obrigatórias na entrega: aparecem no README (relatório) e na galeria de projetos da disciplina.

## O que capturar (mínimo)
1. Tela inicial / menu (se houver).
2. Jogador se movendo com os coletáveis na tela.
3. HUD mostrando o contador de **cada um dos 3 tipos** com valores diferentes de zero.
4. Tela de fim de jogo / vitória (se houver).

## Padrão de nomes
`01_menu.png`, `02_gameplay.png`, `03_hud_contadores.png`, `04_game_over.png`

## Dicas
- Tirar os prints da versão final do jogo, perto da entrega.
- Um GIF curto do jogo rodando (`gameplay.gif`) deixa o README bem melhor.
- Depois de adicionar, colocar as imagens na seção "Capturas de tela" do README principal.

# docs/

Documentação do projeto que não é código. Tudo o que for pedido na entrega e na avaliação fica organizado aqui.

| Arquivo / pasta | Para que serve |
|---|---|
| `screenshots/` | Capturas de tela do jogo funcionando (obrigatório: vão para a galeria de projetos e para o relatório) |
| `checkpoints.md` | Registro do que foi feito em cada checkpoint, antes de preencher a planilha |
| `divisao_tarefas.md` | Quem fez o quê (vai para o relatório) |
| `apresentacao.md` | Roteiro dos slides e da demonstração (máx. 8 min) |
| `fluxo_git.md` | Como o grupo usa branches, commits e pull requests |
| `decisoes.md` | Registro das decisões tomadas pelo grupo (tema, bibliotecas, regras do jogo) |

O **relatório final** fica no `README.md` da raiz do repositório (o enunciado permite entregar no README em vez de PDF).
